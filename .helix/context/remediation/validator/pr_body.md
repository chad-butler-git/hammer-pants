## Breaking Changes Analysis

- Validation semantics tightened (URL parsing)
  - What changed: isURL now parses protocols like browsers (":" delimiter).
  - Impact: Previously accepted malformed URLs may now be rejected.
  - How we handled it: No code changes required specific to URL usage.

- Unicode length handling
  - What changed: isLength accounts for Unicode variation selectors (\uFE0F/\uFE0E).
  - Impact: Inputs with emoji/variation selectors may exceed limits.
  - How we handled it: No direct impacts observed.

- Regex performance fixes
  - What changed: Inefficient regexes fixed in trim/rtrim.
  - Impact: Functional behavior similar; reduced ReDoS risk.
  - How we handled it: No action required.

Additionally, during remediation we aligned application validation and startup behavior:
- Relaxed Joi GUID validation to non-empty strings in shared schemas and routes where IDs are server-assigned
- Adjusted lists POST to not inject id; allow uncategorized items
- Avoid server port collisions by not auto-starting in tests
